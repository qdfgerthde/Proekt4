# 📚 Трекер прочитанных книг

Консольное приложение на Python для учёта прочитанных книг с оценками и статистикой.

## Возможности

- ➕ Добавление книг (автор, название, оценка 1–5, дата)
- 📋 Просмотр всего списка книг
- ⭐ Подсчёт средней оценки
- 👤 Статистика по авторам
- 🗑️ Удаление книги из списка
- 💾 Хранение данных в `books.json`

## Запуск

```bash
python main.py
```

Требования: Python 3.7+, сторонние библиотеки не нужны.

## Пример работы

```
===================================
   📚 Трекер прочитанных книг
===================================
  1. Добавить книгу
  2. Показать все книги
  3. Показать среднюю оценку
  4. Статистика по авторам
  5. Удалить книгу
  6. Выход
===================================
Выберите пункт: 1

--- Добавить книгу ---
Автор: Михаил Булгаков
Название: Мастер и Маргарита
Оценка (1–5): 5
Дата прочтения (дд.мм.гггг, Enter — сегодня): 
✓ Книга «Мастер и Маргарита» добавлена.
```

## Ветки разработки

| Ветка | Функциональность |
|-------|-----------------|
| `feature/add-book` | Добавление книги, проверка дубликатов |
| `feature/list-and-stats` | Список, средняя оценка, статистика по авторам |
| `feature/delete` | Удаление книги |
